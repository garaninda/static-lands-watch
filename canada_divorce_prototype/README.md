# Rebuild — прототип лендинга

Статическая страница без сборки. Открывается напрямую (`index.html`) или через любой статический http-сервер.

## Структура

```
index.html          — разметка
css/style.css       — все стили
images/             — вся графика отдельными файлами
```

## Как заменить картинку

Все изображения подключены в `index.html` обычным `<img src="images/…">`.
Чтобы поставить своё — есть два пути:

1. **Перезаписать файл** с тем же именем в `images/` (расширение то же) — в HTML править ничего не нужно.
2. **Положить файл с другим именем/расширением** (например `hero.jpg`) и поменять `src` в `index.html` — каждое место помечено комментарием.

Все картинки выводятся с `object-fit: cover`, поэтому фото любых пропорций впишется в блок без искажений — обрежутся только края.

## Карта файлов

| Файл | Где используется | Размер холста |
|---|---|---|
| `images/logo.svg` | логотип в шапке, в мокапе продукта, в футере, favicon | 34×34 |
| `images/hero-scene.svg` | главное фото в первом экране | 480×620 (вертикальное) |
| `images/persona-1.svg` … `persona-4.svg` | 4 портрета в блоке «Women Across Canada» | 280×190 (горизонтальное) |
| `images/story-photo.svg` | фото в блоке «Participant story» | 510×680 (вертикальное) |
| `images/notebook.svg` | блокнот в блоке «Soft urgency» | 414×310 (горизонтальное) |
| `images/avatar-1.svg` … `avatar-5.svg` | аватары в отзывах | 40×40 (квадрат) |

Сейчас во всех файлах лежат SVG-заглушки — та же графика, что раньше была нарисована прямо в CSS. Под реальные фото лучше готовить JPG/WebP примерно в указанных пропорциях (для ретины — ×2).

## Что осталось в разметке текстом, а не картинкой

Меняется прямо в `index.html`:

- иконки блока «Clarity / Control / Support» — символы `◌ ◎ ✦`;
- иконки блока «The Goal Isn't Luxury» — эмодзи `🚗 🎒 🏠 🌱`;
- мокап интерфейса продукта (блок «How It Works») — собран версткой, чтобы текст в нём оставался редактируемым.

## Прототип

Форма ничего не отправляет (`alert` вместо submit). Юридические формулировки, комиссии и дисклеймеры помечены блоками «Prototype note» — их заполняет команда внедрения.
